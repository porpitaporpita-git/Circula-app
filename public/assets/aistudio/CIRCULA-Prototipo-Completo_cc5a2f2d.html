1. Resumen Ejecutivo

CIRCULA es una plataforma web que facilita la circulación de libros y materiales educativos entre estudiantes universitarios y lectores en general. El sistema permite a los usuarios donar materiales que ya no utilizan y solicitar materiales disponibles en el catálogo.

🎯 Objetivo: Crear un ecosistema de intercambio gratuito de conocimiento, reduciendo la acumulación de materiales y facilitando el acceso a recursos educativos.

Principios Fundamentales

  • Utilidad antes que comunidad: La plataforma existe para resolver necesidades concretas
  • Mínima fricción: Consulta del catálogo sin registro obligatorio
  • Curaduría central: La organización controla qué se publica
  • Gratuidad: No hay compraventa en el MVP
  • Privacidad por diseño: Nunca se exponen datos de contacto públicamente
  • Mobile-first: Optimizado para dispositivos móviles

2. Características Principales

🔍 Para Visitantes

  • Búsqueda de materiales por texto libre
  • Filtros por categoría, tipo, zona y estado
  • Visualización de fichas detalladas
  • Solicitud de materiales disponibles
  • Formulario de donación simple

👨‍💼 Para Operadores (Backoffice)

  • Gestión de donaciones entrantes
  • Administración del catálogo de materiales
  • Coordinación de solicitudes
  • Gestión de categorías
  • Registro de auditoría completo
  • Panel de métricas en tiempo real

🔒 Seguridad y Privacidad

  • DTOs públicos sanitizados (sin datos de contacto)
  • Validación server-side en todas las mutaciones
  • Rate limiting por endpoint
  • Autenticación con roles (operador/admin)
  • Autorización granular por rol
  • Auditoría completa de acciones críticas

  2. API Layer: Simula endpoints REST con validación y rate limiting
  3. Store: Estado global con reducer y acciones tipadas

Modelo de Datos

Entidades Principales

  • Material: Libro, apuntes, manual, etc. con estado, categoría, zona
  • Donation: Propuesta de donación con estado y notas
  • Request: Solicitud de material con estado y coordinación
  • Category: Categorización de materiales
  • AdminUser: Usuarios del backoffice con roles
  • AuditEntry: Registro de auditoría

Máquinas de Estado

Material: borrador → disponible → reservado → entregado (o inactivo)

Donation: pendiente → contactada → aceptada → en_recepcion → recibida (o rechazada/cancelada)

Request: recibida → coordinacion → reservada → entregada (o cancelada/vencida)

type Route =
  | { view: "home" }
  | { view: "material"; id: string }
  | { view: "donar" }
  | { view: "admin"; tab: Tab };

function parseHash(hash: string): Route {
  const h = hash.replace(/^#\/?/, "");
  const [a, b] = h.split("/");
  if (a === "material" && b) return { view: "material", id: b };
  if (a === "donar") return { view: "donar" };
  if (a === "admin") return { view: "admin", tab: (ADMIN_TABS as string[]).includes(b) ? (b as Tab) : "panel" };
  return { view: "home" };
}

function Shell() {
  const { state } = useStore();
  const [route, setRoute] = useState<Route>(() => parseHash(window.location.hash));
  const [menuOpen, setMenuOpen] = useState(false);
  const pendingSection = useRef<string | null>(null);

  useEffect(() => {
    const onHash = () => {
      setRoute(parseHash(window.location.hash));
      setMenuOpen(false);
    };
    window.addEventListener("hashchange", onHash);
    return () => window.removeEventListener("hashchange", onHash);
  }, []);

  const goTo = useCallback((hash: string) => {
    setMenuOpen(false);
    if (window.location.hash === hash) setRoute(parseHash(hash));
    window.location.hash = hash;
  }, []);

  const goHome = useCallback(() => goTo("#/"), [goTo]);
  const goToMaterial = useCallback((id: string) => goTo(`#/material/${id}`), [goTo]);

  const goSection = useCallback((section: string) => {
    setMenuOpen(false);
    if (parseHash(window.location.hash).view !== "home") {
      pendingSection.current = section;
      goTo("#/");
    } else {
      document.getElementById(section)?.scrollIntoView({ block: "start" });
    }
  }, [goTo]);

  const disponibles = state.materials.filter((m) => m.estado === "disponible").length;

  return (
    <div className="min-h-screen flex flex-col">
      {/* Header con navegación */}
      <header className="sticky top-0 z-50 bg-sage-50/92 backdrop-blur-sm border-b-[3px] border-pine-900">
        <div className="max-w-7xl mx-auto px-4 sm:px-5 md:px-8 h-14 sm:h-16 flex items-center gap-3 sm:gap-6">
          <button onClick={goHome} className="flex items-center gap-2 sm:gap-2.5 focus-ring group shrink-0">
            <LogoMark className="w-8 h-8 sm:w-9 sm:h-9" />
            <span className="font-display font-extrabold text-[19px] sm:text-[22px] text-pine-900">CIRCULA</span>
          </button>
          
          {/* Navegación desktop */}
          <nav className="ml-auto hidden md:flex items-center gap-6">
            <button onClick={() => goSection("catalogo")} className="font-display font-bold text-pine-900">Catálogo</button>
            <button onClick={() => goTo("#/donar")} className="font-display font-bold px-5 py-2.5 bg-marigold-400 text-pine-900 border-2 border-pine-900">
              Donar materiales
            </button>
          </nav>
          
          {/* Menú móvil */}
          <nav className="ml-auto flex md:hidden items-center gap-2">
            <button onClick={() => goTo("#/donar")} className="font-display font-bold px-3 py-2 bg-marigold-400 border-2 border-pine-900">
              Donar
            </button>
            <button onClick={() => setMenuOpen(!menuOpen)} className="p-2 border-2 border-pine-900">
              ☰
            </button>
          </nav>
        </div>
      </header>

      {/* Contenido principal */}
      <div className="flex-1">
        {route.view === "home" && <Home goToMaterial={goToMaterial} goTo={goTo} />}
        {route.view === "material" && <MaterialView id={route.id} goToMaterial={goToMaterial} goHome={goHome} />}
        {route.view === "donar" && <DonateView goHome={goHome} />}
        {route.view === "admin" && <AdminView tab={route.tab} goTo={goTo} />}
      </div>
    </div>
  );
}

export default function App() {
  return (
    <StoreProvider>
      <Shell />
    </StoreProvider>
  );
}

// Rate limiting
export function rateCheck(key: string, max: number, windowMs: number): { allowed: boolean; retryInSec: number } {
  const now = Date.now();
  const all = rlRead();
  const hits = (all[key] ?? []).filter((t) => now - t < windowMs);
  if (hits.length >= max) {
    const retryInSec = Math.ceil((windowMs - (now - hits[0])) / 1000);
    return { allowed: false, retryInSec };
  }
  all[key] = [...hits, now];
  return { allowed: true, retryInSec: 0 };
}

// Validación server-side
function validateRequest(store: StoreLike, r: RequestInput): Record<string, string> {
  const e: Record<string, string> = {};
  const mat = store.state.materials.find((m) => m.id === r.materialId);
  if (!mat) e.materialId = "Este material ya no existe.";
  else if (mat.estado !== "disponible") e.materialId = "Este material ya no está disponible.";
  if (!r.consentimiento) e.consentimiento = "Necesitamos tu permiso.";
  return e;
}

// Autenticación con roles
export function authenticate(store: StoreLike, email: string, pass: string): AuthResult {
  const rl = rateCheck(`login:${email}`, 5, 10 * 60_000);
  if (!rl.allowed) {
    return { ok: false, error: "Demasiados intentos.", retryInSec: rl.retryInSec };
  }
  
  const user = DEMO_USERS.find((u) => u.email === email && u.pass === pass);
  if (!user) {
    store.dispatch({
      type: "LOG_AUDIT",
      entry: { entidad: "Sistema", entidadRef: "—", accion: "Intento fallido", usuario: email, detalle: "Credenciales inválidas." },
    });
    return { ok: false, error: "Credenciales inválidas." };
  }
  
  store.dispatch({ type: "LOGIN", user });
  return { ok: true, user };
}

// Reducer con autorización por rol
function reducer(state: DB, action: Action): DB {
  switch (action.type) {
    case "ADD_CATEGORY": {
      if (action.rol !== "admin") {
        return {
          ...state,
          audit: [audit("Sistema", "—", "Acción denegada", action.usuario, `Intento sin rol admin.`), ...state.audit],
        };
      }
      const cat: Category = { id: `c-${Date.now()}`, nombre: action.nombre, orden: 1, activo: true };
      return {
        ...state,
        categories: [...state.categories, cat],
        audit: [audit("Categoría", cat.nombre, "Creación", action.usuario, "Categoría añadida."), ...state.audit],
      };
    }
    
    case "REQUEST_STATUS": {
      // Efectos sobre el material
      let materials = state.materials;
      if (action.status === "reservada") {
        materials = materials.map((m) =>
          m.id === req.materialId ? { ...m, estado: "reservado" } : m
        );
      }
      if (action.status === "entregada") {
        materials = materials.map((m) =>
          m.id === req.materialId ? { ...m, estado: "entregado", fechaBaja: hoy() } : m
        );
      }
      return { ...state, materials, requests: updatedRequests };
    }
  }
}

export default function Home({ goToMaterial, goTo }: Props) {
  const { state, dispatch } = useStore();
  const api = useApi();
  
  // Filtros
  const [q, setQ] = useState("");
  const [cat, setCat] = useState("");
  const [soloDisponibles, setSoloDisponibles] = useState(true);
  
  // Catálogo desde API pública (DTO sanitizado)
  const visibles = useMemo(() => api.getMaterials(), [api]);
  
  // Filtrado y búsqueda
  const results = useMemo(() => {
    return visibles.filter((m) => {
      if (soloDisponibles && m.estado !== "disponible") return false;
      if (cat && m.categoriaId !== cat) return false;
      if (q) {
        const blob = norm([m.titulo, m.autor, m.descripcion].join(" "));
        if (!norm(q).split(/\s+/).every((w) => blob.includes(w))) return false;
      }
      return true;
    });
  }, [visibles, q, cat, soloDisponibles]);
  
  // Métrica de búsquedas
  useEffect(() => {
    if (q.length > 1) {
      dispatch({ type: "REGISTER_SEARCH", withResults: results.length > 0 });
    }
  }, [q, results.length]);
  
  return (
    <main>
      {/* Hero con búsqueda */}
      <section className="dot-grid">
        <h1>Un libro quieto es un libro que espera circular.</h1>
        <form role="search">
          <input value={q} onChange={(e) => setQ(e.target.value)} placeholder="Buscar..." />
        </form>
      </section>
      
      {/* Grid de materiales */}
      <section id="catalogo">
        {results.map((m) => (
          <MaterialCard key={m.id} material={m} onOpen={goToMaterial} />
        ))}
      </section>
    </main>
  );
}

6. Seguridad y Privacidad

🔒 Medidas Implementadas

1. Protección de Datos

  • DTOs sanitizados: Los endpoints públicos nunca devuelven datos de contacto
  • Separación de datos: Información sensible solo en backoffice autenticado
  • Verificación por grep: Confirmado que ninguna vista pública expone contacto

2. Validación Server-Side

  • Todas las mutaciones pasan por validación en la capa de API
  • Regex para emails y teléfonos
  • Longitudes mínimas y máximas
  • Validación de estados y reglas de negocio

3. Rate Limiting

Endpoint Límite Ventana
POST /api/donations 3 requests 10 minutos
POST /api/requests 4 requests 10 minutos
POST /api/auth 5 intentos 10 minutos por cuenta

4. Autenticación y Autorización

  • Roles: operador (operación diaria) y admin (gestión de categorías)
  • Sesiones auditadas: Login/logout registrados en auditoría
  • Intentos fallidos: Registrados sin revelar si falló email o contraseña
  • Autorización granular: Acciones denegadas se auditan

5. Auditoría Completa

  • Toda acción crítica deja rastro: quién, qué, cuándo
  • Incluye: sesiones, intentos fallidos, acciones denegadas, cambios de estado
  • Filtrable por entidad (Material, Donación, Solicitud, Categoría, Sistema)
⚠️ Nota sobre producción: Este prototipo usa localStorage para persistencia. En producción se debe migrar a un backend real con:
  • Base de datos PostgreSQL
  • API REST con autenticación JWT
  • HTTPS obligatorio
  • Rate limiting en el servidor
  • Validación server-side robusta
  • Backup y recuperación
